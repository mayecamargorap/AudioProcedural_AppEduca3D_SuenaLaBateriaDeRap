# AudioProcedural_AppEduca3D_SuenaLaBateriaDeRap
Este repositorio tiene una aplicación educativa de Unity 3D, cuyo propósito es que el usuario aprenda cómo suenan los tres instrumentos principales de la batería en una pista de rap(🥁 Bombo o Kick, 🥁 Caja o Snare, 🎧 Hi-Hat) ; El usuario se acerca a c/u de los 3 instrumentos y el volumen de este aumentará, permitiéndole identificar su sonido.
