# AudioProcedural_AppEducativa3D_ComoSuenaLaBateriaDeRap
Este repositorio tiene una aplicación educativa de Unity 3D, cuyo propósito es que el usuario aprenda cómo suenan los tres instrumentos principales de la batería en una pista de rap(🥁 Bombo o Kick, 🥁 Caja o Snare, 🎧 Hi-Hat) ; Cuando el usuario se acerca o aleja a c/u de los 3 instrumentos, el volumen de este aumentará o disminuirá, permitiéndole identificar su sonido.
